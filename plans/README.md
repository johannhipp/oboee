## Why this order

- Plan 001 creates the verification floor required for every behavioral
  change after it.
- Plan 002 closes the current paywall and forged-payment bypasses before code
  is rearranged.
- Plan 003 makes the selected testnet/accounting-only payout scope honest,
  resolves the wallet/configuration contract, and replaces the two conflicting
  earnings stores. Real settlement remains a separately authorized project.
- Plan 004 consolidates types only after the security- and money-critical
  state shapes are settled.
- Plans 005 and 006 then make the HTTP and read-model surfaces consume those
  canonical domain contracts.
- Plan 007 splits the UI after the server capabilities and DTOs are stable.
- Plan 008 removes stale documentation last so it describes the landed
  behavior, not an intermediate design.

## Findings considered and rejected

- Restore the deleted policy-v2 system wholesale: rejected. Commit 7143943 is
  an intentional MVP reset; these plans repair the MVP rather than undoing it.
- Split every file or component: rejected. Short route wrappers and focused
  components are already appropriately sized. Only multi-workflow modules and
  duplicated domain/read-model owners are targeted.
- Add a formatter-only or semicolon sweep: rejected. Lint and strict
  typechecking pass; a repository-wide style diff would add review noise
  without fixing an abstraction.
- Hand-edit convex/_generated/api.d.ts: rejected. It is generated and its size
  is dominated by the Better Auth component type surface; regenerate it from
  source changes instead.
- Optimize every Convex lookup immediately: rejected as a standalone project.
  Plan 006 adds bounded pagination and removes avoidable read-model duplication;
  denormalization should wait for measured query limits.
- Create a standalone favicon/font-import cleanup task: rejected as too small.
  If those files are touched in Plan 007, remove the redundant favicon source
  and combine the font imports opportunistically.
- Commit or rewrite ignored .sisyphus plans: rejected. They are local,
  intentionally ignored artifacts from the former static mock phase.
